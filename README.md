# 🚀 KK SQL Academy

**KK SQL Academy** is a complete interactive SQL learning and practice platform designed to help students and developers learn SQL from **absolute basics to advanced database concepts**.

The platform combines structured SQL courses, practical examples, query practice, interactive SQL execution, quizzes, coding challenges, real-world database projects, progress tracking, and final assessments in one learning environment.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
